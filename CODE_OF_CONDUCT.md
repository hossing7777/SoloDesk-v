# Code of Conduct
We pledge to make participation in this project a harassment-free experience for everyone.
Be respectful, welcoming and constructive. Unacceptable behavior includes harassment, discrimination,
personal attacks and publishing others' private information.
Maintainers may remove contributions or ban contributors who violate these rules.
Report problems to the support contact listed in the README. This code is adapted from the Contributor Covenant 2.1.
