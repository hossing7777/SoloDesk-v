# Changelog
All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and this project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-14
### Added
- Clients, projects, time tracking (with Kotlin foreground service), invoices (3 PDF templates), expenses, reports.
- PDF export with static Vazirmatn fonts and RTL support for Persian and Arabic.
- 10 languages, Material 3 light/dark themes, 5 accent colors.
- PIN + biometric lock, JSON backup, CSV export, "Reset all data".
- Offline license keys (Pro), free-tier limits, in-memory demo mode.
- Overdue invoice reminders, recurring invoice duplication.
